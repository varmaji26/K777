# **App Name**: Matka Genius

## Core Features:

- Game Selection: Display a landing page with game options like Milan Night, Milan Day, and Time Bazar Day, each with open and close times.
- Betting Interface: Provide a betting page for each game type, allowing users to select a session (open or close), enter a digit, and enter points.
- Bid Management: Display current bids in a table format with options to remove bids before submission.
- User Authentication: Implement user authentication to allow both anonymous and authenticated users to access all functionalities.
- Support Access: Provide quick access buttons for depositing funds and contacting WhatsApp support.
- Personalized AI Strategy Tips: Provide a tool to generate personalized strategy tips for Matka King, that lets the user to provide a short user query to guide the tool. These personalized tips will then be rendered using reasoning based on the LLM response. The tool is optional.
- Scrolling Notices: Feature a scrolling notice section with game timing updates and important announcements.

## Style Guidelines:

- Primary color: Indigo (#4f46e5) for main buttons and accents, providing a modern, trustworthy feel.
- Background color: Desaturated Yellow (#facc15) to create an exciting yet user-friendly interface (HSL: 50, 90%, 60%, 95%).
- Accent color: Teal (#38b2ac) for highlights and interactive elements. The teal color (analogous to Indigo) gives an exciting vibe and good contrast to the Yellow
- Headline font: 'Space Grotesk' (sans-serif) for headlines and key UI elements, offering a clean, modern, techy feel
- Body font: 'Inter' (sans-serif) for body text and UI descriptions, ensuring readability and a contemporary look.
- Use simple, geometric icons to represent different game types and navigation options.
- Incorporate subtle transitions and hover effects on buttons and interactive elements for enhanced user experience.
